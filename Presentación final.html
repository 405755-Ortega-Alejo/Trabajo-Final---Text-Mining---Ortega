2. Desarrollo y Análisis de Datos

A continuación, se presenta el código utilizado para el análisis de los datos, junto con los gráficos generados que visualizan los resultados.

                    
                        # Código de ejemplo para el análisis de sentimientos
                        import pandas as pd
                        import nltk
                        from nltk.sentiment import SentimentIntensityAnalyzer

                        # Cargar el corpus
                        corpus = pd.read_csv("biblia_reina_valera_1909.csv")

                        # Inicializar el analizador de sentimientos
                        sia = SentimentIntensityAnalyzer()

                        # Aplicar el análisis de sentimientos a cada versículo
                        corpus['sentimiento'] = corpus['texto'].apply(lambda texto: sia.polarity_scores(texto)['compound'])

                        # Visualizar los resultados
                        import matplotlib.pyplot as plt

                        plt.figure(figsize=(10, 6))
                        plt.hist(corpus['sentimiento'], bins=30, color='skyblue', edgecolor='black')
                        plt.title('Distribución de Sentimientos en la Biblia Reina-Valera 1909')
                        plt.xlabel('Puntuación de Sentimiento')
                        plt.ylabel('Frecuencia')
                        plt.show()

3. Conclusiones

El análisis de minería de texto sobre el corpus bíblico de la Reina-Valera 1909 ha permitido identificar patrones y tendencias en la expresión de emociones morales. Los resultados sugieren que existe una estructura afectiva discernible que subyace a las narrativas sagradas, donde emociones como la culpa y el arrepentimiento se asocian a contextos y personajes específicos.

La combinación de herramientas de sociología computacional y la teoría de las emociones ha demostrado ser una metodología fructífera para explorar textos complejos desde una nueva perspectiva. Este enfoque no solo complementa la hermenéutica tradicional, sino que también abre nuevas vías de investigación para comprender la dimensión afectiva del lenguaje religioso y su impacto cultural.
